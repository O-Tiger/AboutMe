# AboutMe

The personal side of [O-Tiger](https://o-tiger.github.io/O-Tiger/): older projects, anime and gaming, and the keyboard easter eggs. Split out of the professional portfolio.

React 19 + Vite, bilingual (PT/EN). Built output is committed to `docs/` and served by GitHub Pages at `/AboutMe/`.

```bash
npm ci
npm run dev      # local dev server
npm run build    # writes the site to docs/
```
